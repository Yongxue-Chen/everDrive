# everDrive 映射与 Remote 管理 UI 设计

## 目标

修复当前映射管理与 remote 配置的核心问题：

1. 前端界面仍有大量英文文案，需要统一为中文。
2. 映射管理页只有只读列表，没有创建、编辑、启停、删除等完整管理能力。
3. 映射创建时本地路径只能手输，不能浏览服务器目录。
4. 映射创建时远端云盘可能为空，且不会自动从 rclone 已配置的 remotes 中刷新。
5. remote 总容量缺少 UI 输入入口，导致容量模型不可维护。
6. `rclone rcd` 连接认证不应要求用户在 UI 中手动录入，而应默认使用 `.env`。

## 当前状态

- 映射页 `frontend/src/pages/MappingTasksPage.tsx` 当前仅支持列表和基础表单。
- 前端 `mock/live` 双模式仍保留。
- 后端已有映射任务 CRUD 接口。
- 后端已有 remote 同步接口 `POST /api/remotes/sync`。
- 后端已有 remote 容量更新接口 `PATCH /api/remotes/:remoteId/capacity`。
- 后端目前没有服务器目录浏览接口。

## 设计决策

### 1. 保留 `mock/live` 双模式

- 不移除当前数据源切换能力。
- 页面显式展示当前模式。
- `mock` 模式下明确提示数据与写操作均为模拟结果。

### 2. 将映射页升级为单页完整管理界面

保留现有 `/mapping-tasks` 路由，不新增独立编辑页。页面拆成两部分：

- 顶部工具区：标题、当前数据源状态、刷新按钮、新建映射按钮。
- 主体内容：
  - 左侧/上方为映射任务列表，展示关键信息和行级操作。
  - 右侧/下方为映射表单，用于新建或编辑当前选中的映射。

### 3. 映射任务支持的功能

- 列表查看
- 新建映射
- 编辑已有映射
- 启用/停用映射
- 软删除映射
- 刷新列表
- 明确区分模拟数据与真实数据
- 浏览服务器目录并回填本地路径
- 自动同步当前 rclone 已配置的 remotes

### 4. 字段语义调整

- `预估数据量`
  - 仅在分片模式显示。
  - 用于校验多个远端总可用容量是否足够，不作为容量配额。
- `优先级`
  - 在 UI 中改名为“绑定顺序”。
  - 单盘模式：仅第一个绑定有效。
  - 冗余模式：第一个是主盘，其余是备份盘。
  - 分片模式：仅作为展示顺序，不表示容量份额。

### 5. 服务器目录选择器

需要新增目录浏览接口，供前端弹窗使用。

能力要求：

- 浏览服务器目录树并返回真实绝对路径
- 支持点击进入子目录和回到上级目录
- 返回目录名、绝对路径、是否可继续进入
- 限制在预定义白名单根目录内，避免浏览整机任意路径

前端交互：

- 本地路径输入框改为“已选路径 + 选择目录”按钮
- 点击后打开目录选择弹窗
- 选中目录后将绝对路径写入表单

### 6. Remote 自动同步与可选列表

映射页在加载时应自动触发一次 remote 同步：

- 先调用 `POST /api/remotes/sync`，从 rclone 当前配置中拉取 remotes
- 再调用 `GET /api/remotes`，作为映射表单下拉选项

如果同步后仍为空，则明确提示：

- 当前没有可绑定云盘
- 需要先在 rclone 配置 remote

### 7. Remote 容量配置

每个 remote 需要支持手动输入总容量：

- `totalCapacity`
- `reservedCapacity` 可保留
- `usedCapacity` 继续由系统自动统计

容量规则：

- 总容量：用户手动维护
- 已用容量：后端自动检测/聚合
- 剩余容量：后端计算展示

这属于 remote 级配置，不放进映射绑定表单，也不做“子目录独立配额”。

前端交互：

- 在云盘列表页增加“编辑容量”入口
- 支持修改总容量、预留容量、告警阈值
- 保存后刷新对应 remote 卡片

### 8. rclone rcd 认证来源

`rclone rcd` 的连接认证默认直接来自 `.env`：

- URL、用户名、密码不再要求用户手填
- 设置页显示“当前由环境变量提供”
- 如果后续需要在线修改，再单独设计持久化配置入口

## 页面交互

### 映射页

- 中文标题和中文错误/加载文案
- 当前数据源状态与模拟数据提示
- 新建映射入口
- 刷新按钮
- 页面加载自动同步 rclone remotes
- 列表与表单联动
- 本地路径目录选择弹窗

### 云盘页

- 远端卡片展示总容量、已用容量、剩余容量、健康状态
- 每张卡片提供“编辑容量”入口
- 已用容量只读展示

### 设置页

- `rclone rcd` URL 可展示
- 用户名/密码显示为环境变量来源说明
- 不要求用户手填认证信息

## 数据流

### 读操作

- 页面加载时先同步 remotes，再获取 remote 列表与映射列表。
- 表单创建模式默认空表单。
- 点击某条映射的“编辑”后，将该条数据加载到表单。

### 写操作

- 新建：提交到 `POST /api/mapping-tasks`
- 编辑：提交到 `PATCH /api/mapping-tasks/:taskId`
- 启停：提交到 `PATCH /api/mapping-tasks/:taskId/active`
- 删除：提交到 `DELETE /api/mapping-tasks/:taskId`
- 目录浏览：调用新增目录浏览接口
- remote 自动同步：调用 `POST /api/remotes/sync`
- remote 容量编辑：调用 `PATCH /api/remotes/:remoteId/capacity`

## Mock 模式行为

- `mock` 模式下保留可交互体验，便于验证 UI。
- 映射、remote 容量、状态切换均在前端内存中模拟。
- 页面仍需显著提示“当前为模拟数据”。

## 错误处理

- 请求失败时在页面显示中文错误提示。
- 后端返回校验错误时直接展示错误消息。
- 删除、停用等破坏性操作需要二次确认。
- 目录浏览失败时显示中文错误提示，并允许重新加载当前层级。
