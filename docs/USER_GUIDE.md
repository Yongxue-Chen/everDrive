# everDrive 用户手册

[简体中文](USER_GUIDE.md) | [English](USER_GUIDE.en.md)

## 1. everDrive 是什么

everDrive 是一个面向 NAS 和服务器的“本地目录到多云存储”同步管理服务。

它使用 rclone 执行实际云盘操作，在此基础上提供本地文件扫描、哈希校验、自动同步、镜像删除保护、多云冗余、容量分片、云端迁移、任务队列和 Web 管理界面。

适合以下场景：

- 将 NAS 照片、视频或文档自动归档到云盘。
- 将同一份文件保存到多个云盘，降低单一云盘故障风险。
- 根据多个云盘的剩余容量，把文件分散存储。
- 在本地文件重命名后，尽量将云端文件移动到新路径，避免重新上传。
- 在多个 rclone remote 之间迁移已有云端文件。

当前服务按可信内网单用户场景设计，没有应用登录系统，不应直接暴露到公网。

## 2. 系统组成

| 组件 | 作用 |
| --- | --- |
| 前端 | React 管理界面，默认端口 `43117` |
| 后端 | 扫描、规划、任务调度和 API，默认端口 `43107` |
| MySQL | 保存映射任务、文件索引、云端位置和操作记录 |
| rclone rcd | 执行上传、移动、删除、迁移和云盘配置 |

后端不会把文件内容保存到 MySQL。MySQL 主要保存文件路径、大小、哈希、同步状态和任务记录。

## 3. 三个核心概念

### 3.1 rclone remote

rclone remote 是 rclone 自己的云盘连接配置，例如 `gdrive:`、`onedrive:`、`s3backup:`。

可以在 Web 的“rclone 配置”页面创建、编辑、删除和测试连接。需要浏览器交互授权的 OAuth 云盘，通常仍需进入 rclone 容器执行：

```bash
docker compose exec rclone rclone config
```

### 3.2 业务云盘

业务云盘是 everDrive 对 rclone remote 的管理记录。它增加了：

- 显示名称
- 总容量和预留容量
- 容量告警阈值
- remote 根路径
- 是否启用云端回收站
- 云端回收站路径

一个 rclone remote 当前只能绑定一个业务云盘。

### 3.3 映射任务

映射任务描述“哪个本地目录，以什么规则，同步到哪些业务云盘”。主要配置包括：

- 本地目录
- `archive` 或 `mirror` 同步模式
- 是否加密
- 是否冗余
- 是否分片
- 绑定的业务云盘和远端子目录

## 4. 当前支持的功能

### 4.1 本地文件扫描与校验

- 递归扫描映射目录下的普通文件。
- 跳过符号链接和特殊文件。
- 记录文件大小、修改时间、MD5 和 SHA1。
- 识别新增、修改和本地已删除文件。
- 根据哈希和大小识别可能的重命名。

当前扫描会完整读取文件并计算 MD5 与 SHA1。大量大文件首次扫描可能耗时较长。

### 4.2 自动和手动同步

- 后端按设置中的同步间隔自动运行任务。
- Web“映射任务”页面可以手动触发同步。
- 手动同步会依次加入扫描、重命名检测和同步任务。
- 同一映射任务不会同时执行多个冲突任务。
- 可限制长任务、短任务和单云盘并发数。

当前任务调度队列保存在后端内存中。后端重启后，尚未执行的队列任务和内存中的任务状态不会保留。

### 4.3 Archive 归档模式

归档模式适合备份和长期保留：

- 本地新增文件会上传。
- 本地修改文件会更新云端副本。
- 本地删除文件不会删除云端文件。
- 已同步文件在本地重命名时，系统会尽量移动云端文件到新路径。

### 4.4 Mirror 镜像模式

镜像模式用于让云端尽量跟随本地状态：

- 本地新增和修改会同步到云端。
- 本地删除经过删除宽限期后，会删除云端副本。
- 如果业务云盘启用了自建回收站，删除会改为移动到回收站。
- 如果没有启用回收站，则会直接删除云端文件。

镜像模式存在真实删除风险。首次使用建议选择测试目录，并启用云端回收站。

### 4.5 多云冗余

开启冗余后，同一个文件会上传到所有绑定的活跃业务云盘：

- 第一个绑定盘显示为主盘，其余显示为备份盘。
- 单个云盘上传失败不会阻止其他副本继续上传。
- 后端提供查看冗余状态和重试失败副本的 API。

可在“冗余恢复”页面查看保护状态，并重试失败副本。

### 4.6 容量分片

开启分片后，每个文件只选择一个业务云盘存放：

- 根据容量、预留空间、告警阈值和优先级选择目标盘。
- 优先选择不会超过告警阈值且适合当前文件大小的云盘。
- 已经放置的文件发生变化时，继续更新原来的云盘副本。
- 创建任务时可填写预估数据量，用于校验总可用容量。

分片不是把单个文件切成多个片段。一个文件始终完整存放在一个云盘上。

### 4.7 上传加密

开启加密后：

- 后端使用 `ENCRYPTION_MASTER_KEY` 派生 AES-256-GCM 密钥。
- 上传前生成临时加密文件。
- 云端路径会根据原相对路径生成不可读的哈希路径。
- Docker 模式通过共享临时卷让 rclone 上传加密结果。

可在“加密恢复”页面选择已知加密任务和成功副本，使用服务器当前的 `ENCRYPTION_MASTER_KEY` 解密下载单个文件。必须长期安全保存该密钥；密钥丢失后无法恢复已加密数据。

### 4.8 重命名识别

系统会根据 MD5、SHA1 和文件大小匹配短时间窗口内的“旧路径缺失”和“新路径出现”：

- 匹配成功后保留原文件身份记录。
- 同步阶段优先在云端执行移动或重命名。
- 无法可靠匹配时会按新增和删除处理。

### 4.9 云端回收站

业务云盘可单独启用自建云端回收站：

- 仅在 `mirror` 模式处理本地删除时使用。
- 默认回收站路径为 `.everdrive-trash`。
- 文件按日期和映射任务组织到回收站。
- 后端可定时清理超过保留天数的内容。
- 设置页可以调整保留天数、清理间隔和单次清理数量。

### 4.10 云盘容量和健康检查

- 通过 rclone `operations/about` 读取支持该接口的云盘容量。
- 对不支持真实容量接口的云盘，可手动维护总容量。
- 支持预留容量和告警阈值。
- 定期检查已绑定 rclone remote 是否仍然存在。
- 看板显示云盘健康、用量和告警状态。

### 4.11 云端迁移

后端提供迁移 API，可以把文件从一个业务云盘复制到另一个业务云盘：

- 支持限定相对路径范围。
- 支持指定目标基础路径。
- 可选择迁移完成后移除源副本。
- 迁移通过长任务队列执行。

可在“云端迁移”页面提交迁移任务；选择删除源云端副本时需要明确确认。

### 4.12 rclone 配置中心

Web“rclone 配置”页面支持：

- 查看已配置的 remote。
- 根据 provider 元数据生成配置表单。
- 创建和编辑 remote。
- 测试 remote 根目录连接。
- 删除未绑定业务云盘的 remote。
- 隐藏敏感配置值。

配置中心只调用固定的 rclone RC API，不开放任意 Shell。复杂 OAuth 授权仍需使用容器控制台。

### 4.13 看板、日志与指标

- 看板按映射任务展示文件量、总大小和最近同步状态。
- 看板展示业务云盘容量和健康状态。
- 操作日志记录部分映射、业务云盘、设置和维护操作。
- 提供“操作日志”和“系统指标”页面，以及 `/health`、`/ready` API。

### 4.14 局域网 SMB/SFTP 只读来源

- 映射任务可以选择服务器本地目录，或选择 rclone 配置中的 SMB/SFTP remote。
- SMB/SFTP 来源始终只读；`archive` 和 `mirror` 都不会删除、移动或修改来源文件。
- `mirror` 仅删除或移动目标云盘副本；来源离线、扫描失败或文件数量异常骤降时，本轮不会标记文件缺失。
- 未启用加密时，rclone 直接从来源 remote 复制到目标云盘。
- 启用加密时，文件会先下载到临时目录、加密后上传，并在完成或失败后清理临时文件。
- 映射页面支持来源 remote 选择、目录浏览和连接测试。

## 5. Web 页面说明

| 页面 | 当前能力 |
| --- | --- |
| 工作空间 | 查看映射任务汇总、数据总量、云盘告警和最近任务状态 |
| 映射任务 | 管理本地或 SMB/SFTP 只读来源；浏览来源目录；手动触发同步 |
| 云盘列表 | 创建和维护业务云盘；设置容量、根路径和回收站 |
| rclone 配置 | 管理底层 rclone remote，并测试连接 |
| 云端迁移 | 提交云盘间迁移任务 |
| 冗余恢复 | 查看保护状态并重试失败副本 |
| 操作日志 | 筛选和查看操作记录 |
| 系统指标 | 查看队列、成功率、容量告警和失败任务 |
| 设置 | 调整同步频率、并发、rclone 参数、日志级别和回收站清理策略 |

前端支持 `mock` 和 `live` 两种数据源。实际使用时必须选择“实时后端”；模拟模式的操作不会写入后端。

## 6. 首次使用流程

1. 按 [部署文档](../DEPLOYMENT.md) 启动服务。
2. 确认 `/ready` 返回 HTTP 200。
3. 打开“rclone 配置”，创建或导入至少一个 remote。
4. 测试 remote 连接；OAuth 云盘按提示在容器中完成授权。
5. 打开“云盘列表”，创建业务云盘并绑定 rclone remote。
6. 设置业务云盘容量、预留容量、远端根路径和回收站策略。
7. 打开“映射任务”，选择 `/data/...` 下的本地目录。
8. 首次使用建议选择 `archive` 模式，并只绑定一个测试云盘。
9. 创建任务后点击“手动同步”。
10. 在看板和任务列表观察扫描与同步结果，并到云盘核对文件。

## 7. 常见配置示例

### 照片长期归档

- 模式：`archive`
- 云盘：一个或多个
- 冗余：需要多份副本时开启
- 分片：关闭
- 回收站：可选

本地误删照片时，云端副本仍然保留。

### NAS 目录镜像

- 模式：`mirror`
- 云盘：一个
- 云端回收站：强烈建议开启
- 首次同步：先使用测试目录

本地删除会最终影响云端，使用前必须确认删除行为。

### 多个小容量云盘组成存储池

- 模式：通常选择 `archive`
- 分片：开启
- 冗余：关闭
- 每个业务云盘填写正确容量和预留容量

每个文件会完整存入其中一个云盘，不会被拆分。

## 8. 当前限制

- 没有应用登录和多用户权限，仅适合可信内网。
- 没有内置解密下载或灾难恢复流程。
- 任务队列为内存队列，后端重启后不保留排队任务。
- 大目录扫描会占用较多时间和内存，且当前会为文件计算 MD5 与 SHA1。

- OAuth 云盘通常仍需通过 `rclone config` 完成交互授权。
- rclone provider 表单不能覆盖所有复杂交互式配置流程。
- 服务不是双向同步工具；主要数据流是本地目录或只读 SMB/SFTP 来源到云端。
- 云端已有但数据库未记录的文件不会自动导入成本地文件。

## 9. 数据安全建议

- 首次使用先选择 `archive` 模式和测试目录。
- 使用 `mirror` 前启用云端回收站，并验证恢复流程。
- 不要随意更换或丢失 `ENCRYPTION_MASTER_KEY`。
- 定期备份 MySQL 数据和 `rclone_config` 数据卷。
- 不要执行 `docker compose down -v`，除非确认可以删除数据库和 rclone 配置卷。
- 前端只能在可信局域网、VPN 或带鉴权的反向代理后访问。
- 定期检查失败任务、容量告警和云盘连接状态。
